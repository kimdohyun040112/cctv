🎥 CCTV 영상

영상을 불러오세요

MP4 등의 CCTV 영상을 선택하면 분석할 수 있습니다.

📌 사용 방법:
1. CORS 허용 영상 URL을 입력하거나 파일 선택
2. "분석 시작" 버튼 클릭
3. 실시간 속도 감지 및 경고 수신
🔗 직접 재생 가능한 영상 URL(.mp4 등)을 입력하세요.

⚙️ 감지 설정

💡 설정 설명:
• 제한속도: 법적 속도 제한
• 경고 기준: 경보 트리거 속도
• 픽셀/거리: 화면 보정값 (값이 작을수록 속도 높게 계산)

📊 실시간 통계

감지 차량 0
현재 과속 0
경고 횟수 0
평균 위반 속도 0.0 km/h

🚨 과속 경고 로그

시간 차량 속도 메시지
아직 과속 경고가 없습니다.

❓ 도움말

🎬 영상 로드 방법 URL 입력 후 "URL 불러오기" 버튼을 클릭합니다. CORS 허용이 필요합니다.

⚙️ 감지 파라미터 • 제한속도: 법적 속도 제한
• 경고 기준: 경보 트리거 속도
• 픽셀/거리 보정: 값이 작을수록 속도 높게 계산됨
• 카메라 FPS: 영상 프레임률

📊 통계 감지된 차량 수, 과속 현황, 경고 로그를 실시간으로 표시합니다.

🔊 음성 경고 과속 감지 시 텍스트-음성 변환으로 경고합니다.

💾 데이터 저장 경고 로그를 JSON 형식으로 다운로드할 수 있습니다.
